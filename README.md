# Almeida & Associados — demonstração

Landing page estética em HTML, CSS e JavaScript. Abra `index.html` ou publique os arquivos em qualquer hospedagem estética.

## Personalização
Edite `js/config.js` para alterar profissionais, imagens, contatos, endereço, horários e visibilidade das seções opcionais. Edite `index.html` para os textos institucionais e `css/style.css` para o visual. As imagens remotas são ilustrativas e precisam ser substituídas por imagens autorizadas; fontes e fotografias dependem de conexão.

Antes de publicar, substitua a identidade fictícia, preencha e verifique inscrições profissionais e contatos, revise textos e áreas de atuação, configure URL canonical e Open Graph conforme o domínio real e submeta o conteúdo à revisão do escritório responsável. Inclua polética de privacidade e dados estruturados apenas quando houver informações reais aplicáveis.
